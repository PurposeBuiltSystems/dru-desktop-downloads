# DRU Desktop Scan Tools

Official [Mac download](https://github.com/PurposeBuiltSystems/dru-desktop-downloads/releases/tag/desktop-v1) from PurposeBuilt Systems.

Apple silicon Mac with macOS 26 or newer. Local four-bit photo reconstruction, guided repair, model viewing, estimated measurements and exports. Developer ID signed and notarized by Apple.

Start a 14-day trial with your own scans, with no payment method or automatic charge. A major-version-1 license costs US$99 once. Active paid DRU Pro subscriptions include desktop processing with periodic online renewal. Viewing and downloading owned models remain free. Managed cloud processing is under development.

Estimated measurements and inferred geometry require independent verification. Photograph coverage and triangulated photo support affect success and completeness. See the release notes for setup, hardware testing and limitations.
