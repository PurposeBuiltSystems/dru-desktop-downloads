# PurposeBuilt Scan Tools

Local reconstruction, guided repair and model exports for Digital ROW Utilities and BridgeCheck AR.

## Downloads

- [Windows x64 installer](https://github.com/PurposeBuiltSystems/dru-desktop-downloads/releases/download/desktop-v1/PurposeBuilt-Scan-Tools-Windows-x64.exe), Windows 10 version 2004 or newer. The installer is unsigned and may show an unknown-publisher warning. Interactive Google/Apple sign-in and visual verification on a personal Windows PC remain pending.
- [Apple silicon Mac download](https://github.com/PurposeBuiltSystems/dru-desktop-downloads/releases/download/desktop-v1/DRU-Desktop-Scan-Tools-macOS-arm64.zip), macOS 26 or newer. Developer ID signed, notarized and stapled.

Version 1.0. A 14-day trial requires no payment method. A $99 one-time desktop license covers major version 1. Active DRU Pro accounts have desktop access through sign-in.

Windows installation, encrypted licensing, real trial activation, license-file import/export, synthetic photo reconstruction, branded model exports, local library/viewer/repair pages, Unicode paths and preservation of customer data through reinstall and uninstall passed on a Windows runner. Synthetic tests do not establish physical measurement accuracy.

## Scan Cloud

[Open Scan Cloud](https://scan-cloud-production.up.railway.app) for hosted processing and sharing at $19.99/month. Existing active DRU Pro accounts can use their subscription. Outside recipients can view and download a finished model without an account or app. Sharing links expire after 30 days and can be revoked. Anyone holding a link can forward it. Original source photos stay private.

## Accuracy

Reconstructed geometry, measurements and inferred repaired surfaces require independent verification before inspection or engineering decisions. Preserve original capture data.

## Windows build source

The Windows build source and workflow are in this repository. The installer uses the shared client engine and published four-bit model artifact. Backend service source, credentials and customer scans are excluded.
